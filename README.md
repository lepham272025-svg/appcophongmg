# AI BẢN LÀNG EM – BÉ KHÁM PHÁ ĐIỆN BIÊN KỲ DIỆU
**Tên tiếng Anh:** Dien Bien Kids Explorer AI  
**Giáo viên thực hiện:** Lò Thị Phong  
**Trường học:** Trường Mầm non Thanh Yên (Xã Thanh Yên, tỉnh Điện Biên)  
**Đối tượng:** Trẻ mẫu giáo 5–6 tuổi (Năm học 2026–2027)  

> *"Mỗi em bé là một nhà khám phá – Mỗi bản làng là một kho tàng tri thức."*

---

## 🌟 TỔNG QUAN DỰ ÁN

**AI Bản Làng Em** là hệ sinh thái web giáo dục mầm non tích hợp trợ lý AI sư phạm, được thiết kế chuyên biệt cho trẻ 5–6 tuổi và giáo viên tại vùng đất Điện Biên giàu truyền thống lịch sử, văn hóa.

Ứng dụng sở hữu phong cách hoạt hình 2.5D tươi sáng, đáng yêu với chủ đề thiên nhiên Điện Biên (hoa ban, cánh đồng Mường Thanh, mái nhà sàn, dòng suối Nậm Rốm) cùng nhân vật hoạt hình dẫn đường **Bạn Ban Nhỏ**.

## 🚀 DANH SÁCH TÍNH NĂNG ĐÃ HOÀN THÀNH

- [x] Hệ thống âm thanh tổng hợp đa âm điệu (Web Audio API: chuông marimba khen thưởng, tiếng gõ gỗ dịu êm, pháo hoa ăn mừng) không phụ thuộc tải tệp MP3 ngoài.
- [x] Huy hiệu ngôi sao khích lệ tinh thần tích cực, không trừ điểm phạt, không xếp hạng so sánh giữa các bé.

### II. Bản đồ Khám phá Điện Biên (6 Khu vực)
1. **Vườn Hoa Ban:** Khám phá đặc điểm hoa ban 5 cánh, hoa ban trắng/hồng, mùa hoa nở tháng 3.
2. **Cánh Đồng Mường Thanh:** Cánh đồng lòng chảo lớn nhất Tây Bắc, hạt gạo Điện Biên thơm dẻo, bác nông dân và chú trâu chăm chỉ.
3. **Núi Rừng Xanh:** Cây xanh che chở bản làng, động vật rừng, giáo dục bảo vệ cây non.
4. **Ngôi Nhà Bản Em:** Nhà sàn truyền thống đồng bào Thái, thanh khau cút đón may mắn, bếp lửa sum vầy.
5. **Phiên Chợ Sắc Màu:** Nhận biết rau củ quả tươi ngon, sắc thổ cẩm và kỹ năng chào hỏi, cảm ơn lịch sự.
6. **Dòng Suối Trong Xanh:** Dòng suối Nậm Rốm, thí nghiệm vật nổi - chìm, giữ nguồn nước sạch.

*Mỗi khu vực đều có: Thẻ kiến thức có giọng đọc, Câu đố tương tác nhanh, Kết nối trải nghiệm STEAM và Trò chơi liên quan.*

### III. Hệ thống 6 Trò chơi Tương tác (Hoạt động thực sự)
- [x] **Trò chơi 1: Bé Đếm Hoa Ban:** 3 mức độ (Dễ: 1-5, Vừa: 1-8, Thử thách: 1-10), hoa ban nở ngẫu nhiên trên đồi cỏ, kiểm tra số lượng và phản hồi âm thanh.
- [x] **Trò chơi 2: Chữ Cái Quê Em:** Nhận biết chữ cái B, N, S, T, L qua từ ngữ bản địa (Ban, Núi, Suối, Trâu, Lúa), nghe âm thanh và ghép chữ cái.
- [x] **Trò chơi 3: Xây Ngôi Nhà Của Bé:** Nhận biết hình tam giác, hình chữ nhật, hình vuông, hình tròn; hỗ trợ chạm chọn - chạm đặt trên màn hình cảm ứng.
- [x] **Trò chơi 4: Chợ Phiên Sắc Màu:** Phân loại quả màu đỏ, so sánh đĩa ngô nhiều hơn/ít hơn, tìm củ quả hình tròn.
- [x] **Trò chơi 5: Bé Bảo Vệ Bản Làng Xanh:** Tình huống bảo vệ môi trường, tiết kiệm nước, chăm sóc cây, giải thích tích cực, không dọa nạt trẻ.
- [x] **Trò chơi 6: Tìm Đường Về Bản:** Mê cung 4x4, 5x5, 6x6, điều khiển bằng 4 nút mũi tên lớn hoặc chạm trực tiếp vào ô liền kề để đưa Bạn Ban Nhỏ về nhà sàn.

### IV. Thư viện Truyện kể Mầm non
- [x] Bộ 3 truyện mẫu minh họa:
  1. *Bạn Ban Nhỏ tìm mùa xuân*
  2. *Hạt Lúa Nhỏ và cánh đồng xanh Mường Thanh*
  3. *Dòng Suối Biết Giữ Sạch*
- [x] Chế độ lật trang, đọc truyện bằng giọng nói tiếng Việt, câu hỏi gợi mở tư duy và hoạt động trải nghiệm sau truyện.

### V. Góc STEAM Trải nghiệm
- [x] 5 hoạt động STEAM mầm non chuẩn:
  1. Làm bông hoa ban bằng giấy mềm
  2. Thiết kế mô hình bản làng bằng hộp giấy tái chế
  3. Khám phá vật nổi và vật chìm bên dòng suối
  4. Gieo hạt mầm lúa và sổ nhật ký mầm xanh
  5. Tranh cánh đồng Mường Thanh bằng vật liệu tái sử dụng
- [x] Tích hợp nút **In hướng dẫn** chuyên dụng cho giáo viên mang vào lớp thực hành.

### VI. Trợ lý AI của Cô Phong & Backend Full-Stack
- [x] Máy chủ Express kết nối `@google/genai` (mô hình `gemini-3.8-flash`) phía server:
  - `POST /api/ai/lesson`: AI tạo Kế hoạch hoạt động (Giáo án) 10 mục chuẩn sư phạm.
  - `POST /api/ai/story`: AI sáng tác truyện tranh thiếu nhi mầm non Điện Biên.
  - `POST /api/ai/questions`: AI tạo bộ câu hỏi trắc nghiệm tương tác.
  - `POST /api/ai/feedback`: AI gợi ý nhận xét sư phạm khích lệ dựa trên ghi chú quan sát.
- [x] Chế độ ngoại tuyến / Fallback thông minh: khi chưa cấu hình API key, hệ thống hiển thị chính xác trạng thái và tải giáo án/học liệu mẫu sư phạm kiểm duyệt, không làm đơ ứng dụng.

### VII. Quản lý lớp học & Minh chứng Dự thi
- [x] Bảng điều khiển quản lý: Học liệu, Hoạt động, Lớp học, Nhật ký triển khai.
- [x] Theo dõi sự phát triển trẻ theo 5 lĩnh vực của Bộ GD&ĐT (Thể chất, Nhận thức, Ngôn ngữ, Tình cảm - KNXH, Thẩm mỹ) với các mức độ "Cần hỗ trợ", "Đang phát triển", "Thể hiện độc lập".

## 🛠️ HƯỚNG DẪN CÀI ĐẶT & CHẠY LOCAL

### Yêu cầu môi trường
- Node.js version 18 trở lên
- npm hoặc yarn

### Các bước khởi chạy:
```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Cấu hình biến môi trường (xem .env.example)
cp .env.example .env
# Điền GEMINI_API_KEY nếu có

# 3. Chạy môi trường phát triển (Full-stack Server + Client)
npm run dev

# Ứng dụng chạy tại: http://localhost:3000
```

### Build & Deploy:
```bash
# Kiểm tra TypeScript
npm run lint

# Build bản tối ưu hóa
npm run build

# Chạy bản production
npm start
```

## 🚀 HƯỚNG DẪN TRIỂN KHAI TRÊN VERCEL

1. Đẩy mã nguồn lên kho lưu trữ GitHub của bạn.
2. Truy cập [Vercel Dashboard](https://vercel.com) -> Chọn **Add New Project** -> Chọn repository GitHub.
3. Framework Preset: chọn **Vite** (hoặc Other).
4. Thêm các biến môi trường trong tab **Environment Variables**:
   - `GEMINI_API_KEY`: Khóa API Google AI Studio / Gemini.
   - `APP_URL`: Tên miền triển khai Vercel của bạn.
5. Nhấn **Deploy** và trải nghiệm sản phẩm trực tiếp!
